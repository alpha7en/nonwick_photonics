# nonwick_photonics

Simulation scripts, symbolic verification scripts, and datasets accompanying the paper
*"Non-Wickian Two-Photon Relaxation in Dephased Photonic Networks: First-Order-Blind Diagnostics and Correlation Mpemba Crossings."*

## Setup

```bash
pip install -r requirements.txt   # Python 3.12+, NumPy, SciPy, SymPy
```

All scripts run directly from the repository root with `python -I <script>` and use `float64`/`complex128` arithmetic on CPU.

## Model and conventions

- **Mode indexing:** arrays and JSON matrices use 0-based indices `0..N-1`; optical port labels in the paper are 1-based (`m + 1`).
- **Two-boson basis:** $\mathrm{Sym}^2(\mathbb{C}^N)$ of dimension $D_2 = N(N+1)/2$ ordered lexicographically as $(m, n)$ with $m \le n$.
- **Continuous waveguide arrays:** $\partial_z \rho = -i[H, \rho] + \sum_j \gamma_j (\hat{n}_j \rho \hat{n}_j - \frac{1}{2}\{\hat{n}_j^2, \rho\})$, where single-photon off-diagonal coherences decay at rate $\frac{1}{2}(\gamma_a + \gamma_b)$ and two-photon NOON coherences at $2(\gamma_a + \gamma_b)$.
- **Discrete Clements meshes:** alternating even/odd MZI layers with beam-splitter angle $\theta$ followed by independent per-layer Gaussian phase noise $\phi_j \sim \mathcal{N}(0, \gamma_{\mathrm{layer}})$.
- **Deterministic graph families:**
  - *Small-world chorded rings (`graph_small_world(N)`):* unit ring plus weight-$0.85$ chords $(0, 3), (2, 6)$ for $N = 8$, and $(c, (c + N/2 - 1) \bmod N)$ for $c \in \{0, 3, \dots\}$ at $N > 8$.
  - *Modular bridge (`graph_modular_bridge(N, J_bridge)`):* two chorded $(N/2)$-site rings (internal chords of weight $0.8$) linked by a single bridge edge of weight $J_{\mathrm{bridge}}$.

## Reproducing the paper

Every stochastic run uses an explicit `numpy.random.default_rng(SEED)` integer seed; deterministic runs contain no RNG calls.

| Paper item | Script | Output (`data/`) | Seed | Run time |
|---|---|---|---|---|
| Figs. 1, 6; Table II | `simulations/clements_fsw.py` | `clements_fsw.json` | `20261120` | ~15 s |
| Figs. 3, 5 | `simulations/metameric_maps.py` | `metameric_maps.json` | `20261124` | ~36 s |
| Figs. 4, 5 | `simulations/core_networks.py` | `core_networks.json` | `20261119` | ~3 min |
| Fig. 7 | `simulations/diagnostics.py` | `diagnostics.json` | `20261119` | ~4 s |
| Fig. 8; Table II (bounds) | `simulations/imperfections.py` | `imperfections.json` | deterministic | ~26 s |
| Fig. 9 | `simulations/higher_order.py` | `higher_order.json` | deterministic | ~11 s |
| Theorems 1, 2; Eq. (16); App. A, B.2 | `proofs/algebra_and_witness.py` | stdout | `20261119`, `424242`, `333333` | ~10 s |
| Theorems 3, 4; Sec. II.C, III; App. B.1, B.3--B.4 | `proofs/spectral_and_kr.py` | stdout | deterministic | ~10 s |

*(Fig. 2 is an analytical schematic; Table I compiles published platform parameters from the cited references.)*

To verify all analytical identities and regenerate every dataset from scratch (in dependency order; `metameric_maps.py` reads `core_networks.json` and `clements_fsw.json`):

```bash
python -I proofs/algebra_and_witness.py
python -I proofs/spectral_and_kr.py

python -I simulations/core_networks.py
python -I simulations/clements_fsw.py
python -I simulations/metameric_maps.py
python -I simulations/diagnostics.py
python -I simulations/imperfections.py
python -I simulations/higher_order.py
```
